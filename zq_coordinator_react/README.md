# ZQ_COORDINATOR React Bridge v2.10

A self-contained futuristic dashboard interface for repository management with Gemini AI integration.

## Quick Start

1. Open `index.html` in any modern browser
2. Enter your Gemini API key when prompted
3. Start using the Master Control Room!

## Features

- Master Control Room with AI chat
- Feedback Agent sidecar
- Live console/logs
- Responsive design
- Dark theme
- Gemini 2.5 Flash integration

No build tools required - fully standalone.

**Command to demo:** `start zq_coordinator_react/index.html`
