## Clone & Run (Dev Mode)

```powershell
# 1. Clone
git clone https://github.com/zubinqayam/ZQ_Taskbox.git
cd ZQ_Taskbox

# 2. Create + activate venv
python -m venv venv
.\venv\Scripts\Activate.ps1

# 3. Install dependencies
pip install kivy[base] pandas openpyxl requests

# 4. Run
python main.py
```

**OR** just double-click / right-click `run.ps1` → "Run with PowerShell" (handles venv + deps automatically).

## Build Windows .exe

### Step-by-step

```powershell
# 1. Activate venv
.\venv\Scripts\Activate.ps1

# 2. Install PyInstaller
pip install pyinstaller

# 3. Build single-file executable
pyinstaller --onefile --windowed `
    --add-data "ui.kv;." `
    --name "ZQ_Taskbox" `
    main.py
```

### Output
- `dist\ZQ_Taskbox.exe` — standalone, no Python required on target machine

### Known Issues & Fixes

| Issue | Fix |
|-------|-----|
| `kivy_deps.sdl2` missing | `pip install kivy_deps.sdl2 kivy_deps.glew` then rebuild |
| `types` module collision | Already fixed — `types.py` is now a shim; real enums in `zq_types.py` |
| `self.root.ids` is None | Already fixed — `_render_lists()` deferred via `Clock.schedule_once` |
| App launches but no window | Add `--windowed` flag or set `KIVY_NO_CONSOLELOG=1` env var |
| Missing `ui.kv` at runtime | Ensure `--add-data "ui.kv;."` is in PyInstaller command |

### PyInstaller .spec (advanced)

After first build, edit `ZQ_Taskbox.spec` and add to `datas`:

```python
datas=[
    ('ui.kv', '.'),
],
```

Then rebuild with:
```powershell
pyinstaller ZQ_Taskbox.spec
```

## Build Android .apk

> **Requires Linux or WSL2** (Buildozer does not run natively on Windows)

### Step-by-step (WSL2 / Ubuntu)

```bash
# 1. Install system deps
sudo apt update && sudo apt install -y \
    python3-pip git zip unzip openjdk-17-jdk \
    autoconf automake libtool cmake

# 2. Install buildozer
pip3 install buildozer cython

# 3. Clone repo inside WSL
git clone https://github.com/zubinqayam/ZQ_Taskbox.git
cd ZQ_Taskbox

# 4. Build debug APK
buildozer android debug
```

### Output
- `.buildozer/android/platform/build-*/dists/ZQ_Taskbox/bin/ZQ_Taskbox-*.apk`

### buildozer.spec key settings (already configured)

| Key | Value |
|-----|-------|
| `title` | ZQ_Taskbox |
| `package.name` | zq_taskbox |
| `android.api` | 34 |
| `requirements` | python3,kivy,pandas,openpyxl,requests |

## GitHub Checklist

### Before every release

- [ ] All tests pass locally (`python main.py` runs without errors)
- [ ] `requirements.txt` up to date
- [ ] `zq_types.py` is the single source of truth for enums (not `types.py`)
- [ ] No hardcoded API keys or secrets in code
- [ ] `.gitignore` excludes `venv/`, `dist/`, `build/`, `*.json` state files
- [ ] Commit message follows format: `type: short description`

### Release steps

```powershell
# Tag and push
git tag v2.x.x
git push origin main --tags
```

Then on GitHub: **Releases → Draft a new release** → attach `dist\ZQ_Taskbox.exe` and the `.apk`.
